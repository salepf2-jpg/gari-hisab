# گاڑی اور ڈرائیور کا حساب (Gari Hisab)
## Vehicle and Driver Accounting System

A simple, lightweight web application for tracking vehicle and driver expenses in Urdu. Perfect for managing fuel costs, repairs, and advances for your transportation fleet.

### ✨ Features

- **Add Expenses** - Record fuel, repairs, and advances easily
- **Edit & Delete** - Modify or remove records anytime
- **Search Function** - Find records by driver or vehicle name
- **Automatic Totals** - Calculate total expenses instantly
- **Local Storage** - Data persists in your browser (no server needed)
- **Urdu Interface** - Complete RTL (right-to-left) support
- **Mobile Friendly** - Works on all devices

### 🚀 How to Use

1. Open `index.html` in your web browser
2. Fill in the vehicle number, driver name, category, amount, and date
3. Click "اندراج کریں" (Record) to save
4. Use the search box to find specific records
5. Edit or delete records as needed

### 📋 Expense Categories

- **فول (Fuel)** - Petrol/Diesel expenses
- **ادھار / ایڈوانس** - Advance payments to drivers
- **مرمت (Repair)** - Vehicle maintenance and repairs

### 💾 Data Storage

All records are saved locally in your browser using localStorage. No internet connection required after loading the page.
